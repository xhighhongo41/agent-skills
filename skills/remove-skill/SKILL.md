# remove-skill: 導入済みスキルを自エージェントから削除する

> **skill version**: 1.0.0

セッション内で初めて本スキルを使用するときは「remove-skill スキル v1.0.0 を使用します」と宣言する。

`skill-sync` も `register-external-skill` もスキルを消さない。消すのは本スキルだけの役目であり、**消す前に何を消すかを示して確認を取り、消すのは自エージェントの置き場にあるものだけ**とする。

**このスキルは利用者のホームディレクトリ配下のファイルを削除する。** 削除はユーザーの承認を得てから行う。

## 書き込みの範囲（最優先の制約）

**本スキルが削除してよいのは、本スキルを実行しているエージェント自身のコンフィグディレクトリ配下のスキルに限る。**
他のエージェントの置き場にあるスキルは、互換読み込みで自分から見えていても消さない。消したいなら**そのエージェント上で本スキルを実行してもらう**。
自分がどのエージェントとして動いているかが判別できない場合は、**削除しない**。

## 前提と一般化ルール

- **引数**はスキル名（複数可）。無ければ自エージェントの置き場にあるスキルの一覧（名前／由来／版）を示して選んでもらう。
- **由来**は3種に分ける。**収録**（`skill-sync` の配布元の `index.json` に名前がある）、**外部由来**（frontmatter の `metadata` に `origin` がある）、**ローカル固有**（どちらでもない）。
  配布元に接続できないときは、収録かローカル固有かを区別せず「配布元は未確認」とする。
- 自エージェントの判別とスキルの置き場は「既知のエージェントのスキルディレクトリ」の表で引く（`skill-sync` と同じ表。直すときは両方を同時に直す）。
- 必要・不要の設定ファイルは `skill-sync` のもの（設定ディレクトリ直下の `skill-sync.json`）を読み書きする。無ければ作らない。

## 手順

### 1. 自エージェントと置き場を決める

表で引く（環境変数による上書きを優先する）。表に無いエージェントは汎用則（`<設定ディレクトリ>/skills/<スキル名>/`）で探す。判別できなければ削除せず、その旨を報告して止まる。

### 2. 対象を探す

対象のスキルを**自エージェントの置き場だけ**で探す。次の場所にあるものは見つかっても**削除しない**で、その旨と正規の手段を案内する。

| 見つかった場所 | 案内する手段 |
|---|---|
| 他のエージェントの置き場（互換読み込みで見えている） | そのエージェント上で本スキルを実行する |
| プラグイン機構の管理下（Claude Code の `~/.claude/plugins/` 配下など） | プラグイン機構のコマンドでプラグインを外す |
| 配布経路のキャッシュ（OpenCode の `~/.cache/opencode/skills/` など） | 配布元の設定から外し、機構に取り直させる |
| 作業中のリポジトリ配下（プロジェクトスコープ） | リポジトリの持ち物なので、利用者が明示的に指示した場合だけ消す |

名前が見つからなければ、近い名前の候補を示して確認する。

### 3. 示して確認する

対象ごとに次を表にして示し、**確認を1回**得る（複数件でもまとめて1回）。

- パス（実パス）
- 由来（収録／外部由来〈導入元〉／ローカル固有）
- 版（`metadata.version`。無ければ「版無し」）
- ファイル数と本文の行数

**確認が得られるまで消さない。** 確認で外された件は飛ばす。

### 4. 削除する

スキルのディレクトリごと削除する。削除の前に、パスが自エージェントのコンフィグディレクトリ配下であることをもう一度確かめる。
シンボリックリンクなら**リンクだけ**を消し、リンク先は触らない（その旨を報告する）。

### 5. 設定を整える

必要・不要の設定ファイルが**あれば**、由来に応じて次を行う（無ければ何もしない。読めないときも触らない）。

| 由来 | 設定の扱い |
|---|---|
| 収録 | 「不要（`false`）」にするかを尋ねる。不要にすれば `skill-sync` が再び導入を勧めない。尋ねずに書き換えない |
| 外部由来 | その名前のキーを消す（導入元の記録はスキルと一緒に消えたので、設定だけ残しても意味が無い） |
| ローカル固有 | 触らない |

他の項目と未知のキーは変えない。

### 6. 報告する

削除したパス、飛ばしたもの（理由付き）、設定の変更（何をどう書いたか、書き込み先のパス）を示す。
戻したいときは、収録スキルなら `skill-sync`、外部由来なら `register-external-skill` で再導入できることを添える。
多くのエージェントは起動時にスキルを読むので、一覧から消えるのは再起動後である旨も添える。

## 既知のエージェントのスキルディレクトリ

**この表はデータである。** `skill-sync` の同名の表と同じ内容であり、直すときは両方を同時に直す。

| エージェント | ユーザースコープ | `compatibility` の値 | 環境変数による上書き |
|---|---|---|---|
| Claude Code | `~/.claude/skills/` | `claude-code` | `CLAUDE_CONFIG_DIR` |
| OpenAI Codex | `~/.codex/skills/` | `codex` | `CODEX_HOME` |
| OpenCode | `~/.config/opencode/skills/` | `opencode` | `XDG_CONFIG_HOME` / `OPENCODE_CONFIG_DIR` |

Windows では `~` をユーザープロファイル（`%USERPROFILE%`）に読み替える。

## うまくいかないときの確認

- **名前が見つからない**: 綴り、環境変数による置き場の移動、別のエージェント上で走らせていないかを確認する。
- **見つかったが自分の置き場ではない**: 手順2の表のとおり削除しない。案内した手段で消す。
- **削除後もエージェントの一覧に残る**: 起動時に読んだ一覧が残っている。再起動する。
- **削除後に `skill-sync` が「必要×未導入」として導入を勧める**: 設定を不要に直していない。`skill-sync` の確認で不要に直す。
